# US-016 — Search, alerts, and operation center

> As an operator, I want one place to find resources and active problems so that
> the desktop shell speeds up real work.

## Acceptance criteria

- Search returns apps, containers, files, settings, and safe actions with clear types.
- Alerts have severity, source, time, state, and a route to resolution.
- Active/recent operations remain visible across navigation and reconnect.

## Tasks

- [ ] **T-046** Define search index/providers, result permissions, and keyboard interaction.
- [ ] **T-047** Define alert/notification lifecycle and operation-center query/event model.
- [ ] **T-048** Build search results, alert center, operation progress, and accessibility tests.
