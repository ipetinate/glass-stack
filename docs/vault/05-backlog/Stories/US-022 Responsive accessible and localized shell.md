# US-022 — Responsive, accessible, and localized shell

> As a user on different devices or with accessibility needs, I want a readable
> and operable shell so that server management is not desktop-pointer only.

## Acceptance criteria

- Navigation and dashboard have intentional wide, compact, and narrow layouts.
- Supported surface/theme combinations meet contrast, keyboard, focus, target-size, and reduced-motion rules.
- User-facing strings are externalized before a second language is added.

## Tasks

- [ ] **T-064** Design compact/narrow information architecture and responsive widget rules.
- [ ] **T-065** Implement responsive shell plus contrast, focus, keyboard, and motion fixes.
- [ ] **T-066** Introduce localization boundary and automated accessibility/viewport checks.
