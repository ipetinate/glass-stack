# US-015 — Customizable widgets and shortcuts

> As an operator, I want to arrange useful widgets and shortcuts so that the
> home screen matches how I use my server.

## Acceptance criteria

- Supported widgets can be shown, hidden, and ordered.
- Layout persists per user and has a safe reset.
- Shortcuts target installed apps, routes, or validated external URLs.

## Tasks

- [ ] **T-043** Define widget registry, size constraints, preferences, and migration behavior.
- [ ] **T-044** Implement editable layout persistence and responsive placement.
- [ ] **T-045** Replace placeholder shortcuts with create/edit/remove/open flows.
