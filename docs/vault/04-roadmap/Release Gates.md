# Release Gates

## Alpha

- Authenticated real host dashboard.
- Docker inventory and lifecycle.
- Operation/audit records.
- One supported OS/architecture development path.
- No known critical security issue.

## Beta

- Catalog and one app complete end to end.
- File manager and terminal MVP.
- Upgrade/uninstall and state backup.
- amd64 and arm64 CI artifacts.
- Compact responsive shell and accessibility pass.
- No P0 backlog item open.

## 0.1.0

- Installer smoke-tested on supported distributions.
- Restore and failed-upgrade recovery tested.
- Signed checksummed artifacts and SBOM.
- Compatibility and security documentation published.
- P1 defects triaged with no release-blocking issue.
- Fresh-machine user test completes the north-star outcome.
